Multi-Agent Study Orchestrator

Multi-Agent Workflow Engine for Interactive Learning

An asynchronous multi-agent system orchestrating specialized AI agents (Explainer, Notes Maker, Question Generator) to construct stateful, personalized learning pathways using custom MCP tools and a custom RAG pipeline over user notes.

Automated AI Response Judge

Dual-Pipeline LLM Evaluation Microservice for Human Preference & Factual Checking

An automated evaluation engine that predicts which of two LLM responses a human would prefer in style, paired with a separate factual-checking track.

  • Dual-Pipeline Design: A style track and a separate factual track, run together through a FastAPI service. The style track is a fine-tuned DeBERTa-v3-large (KL-divergence loss, label smoothing, gradient accumulation) that predicts human-preferred style and works standalone. The factual track prompts a locally served Qwen 3.5-2B to rate each response and normalizes the ratings into A / B / tie shares; it has not been benchmarked yet.
  • Empirical Benchmarks: DeBERTa-v3 alone, as a preference judge, reached 67.21% accuracy on Anthropic HH-RLHF (50% chance) and 56.96% on LMSYS Chatbot Arena (33.33% chance).
  • Serving & Inference Pipeline: FastAPI service with local CPU PyTorch inference, handling 512-token multi-turn context windows, paired with a Django management interface.

Stack: Python, PyTorch, Hugging Face, Scikit-learn, DeBERTa-v3, Qwen 3.5, FastAPI, Django, NumPy

Real-Time Face Recognition

Offline, Cloud-Independent Biometric Recognition System

A full-stack biometric detection and verification application built to operate in real-time without relying on external cloud APIs or third-party tracking services.

High-Precision Linear Equation System Solver

Exact-Arithmetic Matrix Solver for Arbitrary-Dimension Linear Systems

An algorithmic engine designed to eliminate floating-point approximation error when solving systems of linear equations.

  • Exact Fractional Arithmetic: Developed a custom Fraction numeric data type supporting arbitrary-precision rational arithmetic, completely bypassing IEEE 754 floating-point drift.

  • Implementations: Maintained across both C# (.NET) and modern C++.
