Multi-Agent Study Orchestrator

Autonomous Multi-Agent Workflow Engine for Interactive Learning

An asynchronous multi-agent system orchestrating specialized AI agents (Explainer, Notes Maker, Question Generator) to construct stateful, personalized learning pathways.

  • Architecture: Built on LangGraph and FastAPI, featuring checkpoint-based conversation branching, real-time agent execution tracking, and asynchronous multi-agent message routing.
  • Protocol Integration: Integrated Model Context Protocol (FastMCP) tools with LangChain agents and local LLMs (Gemma) to enable dynamic tool execution without state pollution.
  • Observability: Interactive interface providing live agent workflow visualization, execution logs, and interactive quizzes.

Stack: Python, FastAPI, LangGraph, LangChain, FastMCP, Gemma

Automated AI Response Judge

Dual-Pipeline LLM Evaluation Microservice for Human Preference & Factuality

An automated evaluation engine engineered to score and rank paired LLM responses while actively mitigating sycophancy and superficial stylistic bias.

  • Dual-Pipeline Design: Independent evaluation tracks separating subjective style analysis (fine-tuned DeBERTa-v3-large with KL-divergence loss, label smoothing, gradient accumulation) from factual correctness (zero-shot Qwen 3.5-2B verification).
  • Empirical Benchmarks: Outperformed random baselines (33.3%), scoring 67.21% accuracy on Anthropic HH-RLHF and 56.96% on LMSYS Chatbot Arena evaluation splits.
  • Serving & Inference Pipeline: Asynchronous FastAPI service handling 512-token multi-turn context windows with local PyTorch inference, paired with a Django management interface.

Stack: PyTorch, Hugging Face, DeBERTa-v3, Qwen 3.5, FastAPI, Django, NumPy

Real-Time Edge Face Recognition

Offline, Cloud-Independent Biometric Recognition System

A full-stack biometric detection and verification application built to operate in real-time without relying on external cloud APIs or third-party tracking services.

  • Deep Learning Inference: Integrated lightweight OpenCV deep learning models—FaceDetectorYN (YuNet) for multi-face detection and FaceRecognizerSF (SFace) for high-dimensional feature embedding extraction.
  • Offline Vector Engine: Engineered a local, zero-cloud embedding storage and retrieval mechanism using optimized .npz vector matrices and JSON/Base64 APIs.
  • Application Pipeline: Packaged as an end-to-end Django application supporting live camera stream processing, on-the-fly face registration, and multi-subject recognition.

Stack: Python, OpenCV (YuNet & SFace), Django, NumPy, REST APIs

High-Precision Linear Equation System Solver

Exact-Arithmetic Matrix Solver for Arbitrary-Dimension Linear Systems

An algorithmic engine designed to eliminate floating-point approximation error when solving systems of linear equations.

  • Exact Fractional Arithmetic: Developed a custom Fraction numeric data type supporting arbitrary-precision rational arithmetic, completely bypassing IEEE 754 floating-point drift.
  • Algorithmic Core: Implements a hybridized Gauss Elimination and Gauss-Jordan matrix transformation pipeline with dynamic row-reduction pivoting, supporting determined, under-determined, and inconsistent systems.
  • Implementations: Maintained across both C# (.NET) and modern C++.

Stack: C# (.NET), C++, Matrix Mathematics, Unit Testing
